# PC 자산관리 시스템

사내 데스크톱·노트북 자산관리 웹사이트. PRD 문서 세트와 **v1(MVP) 구현체**를 함께 담고 있다.

## 실행

```bash
pip install -r requirements.txt
python run.py
```

`http://127.0.0.1:8000` · 최초 계정 `admin` / `admin1234` (첫 로그인 시 변경 필요)

## 읽는 순서

1. **Master** §1~5 — 무엇을 왜 만드는지
2. **Master** §7~8 — 관리할 항목과 데이터 구조
3. **v1** — 지금 만들 것
4. **Master** §13 / 각 버전의 열린 이슈 — 다음에 결정할 것

## 문서 규칙

- 요구사항 ID(`FR-xx`)와 데이터 항목 ID(`DM-xx`)는 **Master에서 부여**하고 버전 문서는 이를 참조한다.
- 우선순위는 `Must` / `Should` / `Could` 3단계를 사용한다.
- 확정되지 않은 사항은 각 문서 말미의 **열린 이슈(OI-xx)** 표에 모은다. 추측으로 채우지 않는다.
- 설계 판단의 근거는 본문에 **설계 메모**로 남긴다.

## 확정된 전제

| 항목 | 결정 |
|---|---|
| v1 범위 | 자산 CRUD + 엑셀 I/O, 배정·회수 + 변경 이력, 대시보드 + 검색/필터 |
| 사용자 권한 | v1은 IT 관리자 전용 단일 역할 (`role` 컬럼은 미리 확보) |
| 배포 환경 | 사내 온프레미스 폐쇄망 |
| 인증 | 자체 ID/PW (AD 연동은 v3) |
| 대상 규모 | 임직원 약 1,000명, 자산 약 1,200~1,500대 |
